Essential HTML Skills

HTML
The standard markup language used to structure web pages and their content.
Tables
Structured grids consisting of rows and columns used to display tabular data clearly.
Forms
Interactive sections used to collect user inputs-such as text, choices, and credentials-and send them to a server.
Semantic HTML
Tags like <header>, <article>, and <footer> that convey the actual meaning and purpose of elements to browsers and assistive technologies.
Accessibility
The practice of designing web content that can be easily navigated and understood by everyone,including people with disabilities and screen-reader users.

Web Development Learning Timeline

  1. HTML Basics: The starting point where I learned core concepts like elements, opening and closing tags, attributes, and setting up the basic document structure (<!DOCTYPE html>, <head>, <Body>)
  2. Formatting: Understanding how to structure and style readable content using headings (<h1> to <h6> paragraphs, line breaks, blockquotes, and text styling tags like bold, italics, and inline code.)
  3. Links: Learning how the web connects by using anchor tags (<a>) to link to external websites, navigate between local files, jump to page sections with IDs, and open targets in new tabs.
  4. Images & Lists: Adding visual appeal and orderly structure using the <img> tag (along with key attributes like src and alt for accessibility), paired with ordered, unordered, and description lists.
  5. Tables: Mastering how to organize structured data into rows and columns by using <table>, <thead>, <tbody>, <th>, <td>, <tr>, along with cell merging via colspan and rowspan.
  6. Forms: Building interactive user input forms with elements like <input>, <textarea>, <select>, and <button>, along with validating fields and understanding form submission methods.
  7. Audio & video : Integrating native multimedia into web pages using <audio>, and <video> tags, learning about source fallbacks, formats, and media controls (play, pause, loop, mute).
  8. Semantic HTML: Writing clean meaningful markup using structure tags like <header> <nav>, <main>, <section>, <article>, and <footer>, to improve SEO and screen reader accessibility.
